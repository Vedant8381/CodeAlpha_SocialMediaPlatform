# 🚀 CodeAlpha SocialConnect

A full-stack social media platform built using Django as part of the CodeAlpha Internship Program.

## 📌 Project Overview

SocialConnect is a web-based social media platform where users can create posts, interact with other users, follow people, comment on posts, like/unlike posts, search for users, and receive notifications.

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Profiles
- 📝 Create Posts
- ✏️ Edit Posts
- 🗑️ Delete Posts
- ❤️ Like / Unlike Posts
- 💬 Comment on Posts
- 🤝 Follow / Unfollow Users
- 👥 Followers & Following Lists
- 🔎 Search Users
- 🔔 Notifications System
- 📱 Responsive User Interface
- 🛠️ Django Admin Panel

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Git & GitHub
